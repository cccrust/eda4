# 晶片平面規劃 (Floorplanning) 與電源分配網路 (PDN)

## 概述

晶片平面規劃是實體設計中接在邏輯合成之後的第一個階段。它的核心任務是決定晶片的尺寸 (die size)、形狀 (aspect ratio)，以及主要功能區塊在晶片上的位置。平面規劃的品質直接影響後續的擺置 (placement)、繞線 (routing)、時序收斂 (timing closure) 和功耗表現，是所有後續實體設計工作的基礎。

## 平面規劃在不同設計流程中的角色

### ASIC 平面規劃

在 ASIC 設計流程中，平面規劃由晶片設計者主導，需要將晶片面積劃分給各個功能區塊，例如 CPU 核心、快取記憶體、I/O 電路、類比電路、記憶體陣列等。設計者需決定每個區塊的大小、形狀和相對位置，同時規劃 I/O pad 的位置以及電源網路。ASIC 的平面規劃自由度很高，但也帶來了極大的複雜性。

### FPGA 平面規劃

FPGA 的平面規劃與 ASIC 有根本性的不同。FPGA 廠商已經預先定義了晶片內部的拼貼網格 (tile grid)，包含邏輯區塊、I/O 區塊、BRAM、DSP 等資源的固定位置。設計者無法改變這些資源的實體佈局，只能透過平面規劃約束 (constraints) 將 RTL 層級的邏輯限制到特定的 FPGA 區域，以最佳化效能、功耗和繞線擁塞程度。FPGA 的平面規劃本質上是對預先存在的架構進行資源分配與區域約束。

## 關鍵平面規劃決策

### 晶片縱橫比 (Aspect Ratio)

晶片的形狀由縱橫比決定，定義為晶片高度與寬度的比值。典型的縱橫比接近 1:1 (方形) 以最小化繞線長度，但封裝和製造上的限制有時會要求較為狹長的形狀。縱橫比會影響晶片內部的繞線長度、時序以及散熱特性。

### 核心使用率 (Core Utilization)

核心使用率是指邏輯電路實際佔用的核心面積與晶片核心總面積的比率。典型 ASIC 設計的使用率約在 60% 到 80% 之間，剩餘的空間保留給繞線、緩衝器插入 (buffer insertion)、以及時脈網路。使用率過高會導致繞線資源不足、擁塞加劇，進而使時序難以收斂；使用率過低則浪費晶片面積，增加製造成本。

使用率的計算方式為：

```
utilization = (標準元件總面積 + 巨集區塊總面積) / 核心可利用面積
```

### 區塊佈局 (Block Placement)

大型設計通常包含多個功能區塊或巨集 (macro)，例如 SRAM 記憶體、PLL、類比 IP 等。區塊佈局是將這些巨集放置到核心區域中的適當位置。良好的區塊佈局應考量：

- 各區塊之間的連線關係 (connectivity)
- 資料流方向 (data flow)
- 電源需求
- 散熱考量
- 與 I/O pad 的距離

區塊放置不當會造成嚴重的繞線擁塞和時序問題。典型的策略是將高度相連的區塊彼此靠近放置，以縮短訊號路徑。

### I/O 接腳分配 (I/O Pin Assignment)

I/O 接腳沿著晶片的周邊排列，負責處理晶片與外部世界的訊號、電源和時脈。I/O 接腳分配需要考慮：

- 印刷電路板 (PCB) 層級的連線限制
- I/O pad 的驅動能力和信號完整性 (signal integrity)
- 高速訊號的阻抗匹配
- 電源和接地接腳的數量與分布
- 同時切換輸出 (SSO) 產生的雜訊

好的 I/O 規劃能減少 PCB 的繞線層數和設計複雜度，同時確保訊號品質。

### 階層式平面規劃 (Hierarchical Floorplanning)

在大型晶片設計中，常採用階層式平面規劃：將晶片拆解為多個子區塊 (block/chiplet)，每個子區塊獨立進行後續的擺置與繞線。這種做法的優點在於：

- 降低單次處理的複雜度，使工具能在合理時間內完成運算
- 各區塊可以由不同團隊平行開發
- 重複使用已驗證的區塊 (hard macro reuse)

階層式平面規劃需要在晶片層級定義區塊的邊界 (block boundary) 和接腳位置 (block pins)，以及區塊之間的繞線通道 (routing channels)。

### 硬巨集與軟巨集 (Hard Macros vs Soft Macros)

在平面規劃中區塊可以分為硬巨集和軟巨集：

- **硬巨集 (Hard Macro)**：具有固定尺寸和形狀的區塊，例如 SRAM 編譯器產生的記憶體、PLL、SerDes PHY 等類比 IP。硬巨集在平面規劃中視為不可變更的矩形，只能選擇放置位置和旋轉方向。
- **軟巨集 (Soft Macro)**：只定義邏輯功能但無固定實體尺寸的區塊，例如從 RTL 合成的數位邏輯。軟巨集的面積會隨著目標使用率和繞線資源而變化。

平面規劃工具需要同時處理這兩類區塊，對硬巨集精確定位，對軟巨集則預估面積需求。

### 非矩形區塊

現代平面規劃工具支援非矩形區塊形狀，例如 L 形、T 形或更複雜的多邊形。這在處理類比電路或具有特殊散熱需求的區塊時特別有用。然而，非矩形區塊會增加繞線複雜度，因此在數位設計中仍以矩形區塊為主流。

## 電源分配網路 (Power Distribution Network, PDN)

### PDN 的功能與目標

電源分配網路是負責將封裝接腳上的 Vdd (電源) 和 GND (接地) 電壓傳遞到晶片上每一個電晶體的基礎設施。PDN 必須達成以下目標：

- 在所有工作條件下維持穩定的電壓供應
- 將電壓降控制在可接受的範圍內 (通常小於 Vdd 的 5%)
- 承載晶片運作所需的全部電流
- 減少電源雜訊的傳播

### 電源網格 (Power Grid)

PDN 的核心結構是金屬電源網格，由多層金屬導線交織而成。在現代製程中，晶片包含 10 層以上的金屬層，較低層 (如 M1) 使用較細的金屬線，較高層 (如 M9、M10) 使用較粗的金屬線，適用於長距離電源傳輸。

典型的電源網格結構如下：

- **VDD 和 VSS 條帶 (stripes)**：在高金屬層上以大間距佈置的水平或垂直金屬條
- **VDD 和 VSS 軌道 (rails)**：在低金屬層 (通常是 M1) 中為標準元件提供電源的較細導線
- **導通孔堆疊 (via stacks)**：連接不同金屬層的電源線，降低電阻

### 壓降 (IR Drop)

IR drop 是指電流經過具有電阻的電源網路時產生的電壓下降。IR drop 可分為兩種：

- **靜態 IR drop**：由平均電流消耗和電源網路的直流電阻造成
- **動態 IR drop** (也稱為 Ldi/dt drop)：由瞬間電流變化 (di/dt) 和封裝/晶片寄生電感造成

嚴重的 IR drop 會降低電路速度，甚至導致邏輯錯誤。設計者透過加寬電源線、增加電源網格密度、以及合理分配電源接腳來降低 IR drop。

典型的 IR drop 預算分配如下：

```
封裝與打線接合：2%
C4 銲錫凸塊：1%
晶片電源網格：2%
總計：5%
```

### 電遷移 (Electromigration)

電遷移是當高密度的電流流經金屬導線時，金屬原子因電子撞擊而發生遷移的現象。這會導致金屬線在某些區域變薄 (形成空洞)，最終造成開路；或是在其他區域堆積 (形成突起)，可能造成短路。

電遷移是決定電源網路導線寬度的關鍵因素。設計者必須確保每條電源線的電流密度低於製程技術所允許的 EM 限制。隨著製程微縮，電遷移問題變得更加嚴峻。

### 去耦電容 (Decoupling Capacitors, Decaps)

當電路瞬間需要大量電流時 (例如時脈邊緣觸發大量正反器同時切換)，電源網格的反應速度有限，會導致局部電壓瞬間下降 (voltage droop)。去耦電容是放置在 Vdd 與 GND 之間的電容器，作為局部電荷儲存器，在電壓下降時快速提供電流。

去耦電容的來源包括：

- **專用 decap 單元**：在標準元件庫中提供，以 MOS 電容形式實現
- **非切換邏輯閘**：未被使用的邏輯閘也可貢獻部分電容
- **晶片內建電容**：電源網格本身的金屬間電容

### 電源完整性分析 (Power Integrity Analysis)

電源完整性分析是在設計流程中驗證 PDN 是否滿足要求的關鍵步驟，包含：

- **靜態 IR drop 分析**：計算電源網格在平均電流下的直流電壓降，定位熱點區域
- **動態 IR drop 分析**：模擬電路在最大功耗活動下的瞬態電壓響應，考慮封裝寄生參數和去耦電容效應

若是分析結果不符規格，設計者需回饋修改電源網格、增加去耦電容、或調整擺置以分散功耗密度。

## 電源域 (Power Domains) 與電壓島 (Voltage Islands)

現代低功耗設計常採用多電壓域策略，稱為電壓島或電源域。不同的功能區塊使用不同的電源電壓：

- CPU 核心：0.7V（低電壓模式）或 1.0V（高效能模式）
- I/O 電路：1.8V 或 3.3V
- 記憶體陣列：獨立電壓以最佳化漏電

不同電壓域之間需要使用電平轉換器 (level shifter) 來溝通，並且在實體設計上必須有明確的電源網格劃分。電源域也可以獨立關閉來節省靜態功耗，這種技術稱為電源關斷 (power gating)。

## PG 接腳與電源環

### 電源/接地環 (Power/Ground Rings)

晶片周圍和每個大型巨集周圍都會設置電源/接地環，由最頂層金屬構成，連接封裝的電源接腳並將電力分配到內部的電源網格。環的寬度根據電流需求計算，通常會使用數百微米的寬金屬線。

### PG 接腳 (Power/Ground Pins)

晶片的電源和接地接腳分布直接影響 PDN 的效能。在打線接合 (wire-bond) 封裝中，PG 接腳位於晶片周邊；在覆晶 (flip-chip) 封裝中，PG bump 可以分布於晶片整個面積上，大幅降低 IR drop。

### 電源網格設計方法論

建立有效的電源網格需要依序決定以下參數：

1. **金屬層選擇**：高金屬層 (厚金屬) 用於長距離輸送，低金屬層 (薄金屬) 用於局部分配
2. **條帶寬度與間距**：寬度由電流需求和 EM 限制決定，間距則由 IR drop 目標決定
3. **條帶方向**：相鄰金屬層通常採用正交方向 (例如 M5 水平、M6 垂直) 以形成網格
4. **導通孔陣列**：在電源條帶交叉處放置密集的導通孔陣列以降低電阻

### 電源網路共振 (Power Supply Resonance)

封裝的寄生電感與晶片上的去耦電容在特定頻率下會形成 LC 共振電路。如果電路的切換頻率接近共振頻率，會造成嚴重的電壓漣波 (voltage ripple)。為避免此問題，設計者必須：

- 確保去耦電容的總量足夠，使共振頻率遠高於電路的工作頻率
- 在封裝層級加入適當的 bypass 電容
- 使用不同尺寸的去耦電容以涵蓋寬頻段的雜訊抑制

### 時序驅動的平面規劃

平面規劃不僅影響繞線，也直接影響時序。關鍵路徑 (critical path) 上的元件如果分散在晶片兩端，過長的連線延遲會使時序難以收斂。平面規劃階段可以透過以下方式改善時序：

- 將關鍵路徑上的區塊彼此靠近放置
- 在資料流方向一致的前提下排列區塊
- 預留空間給關鍵路徑的緩衝器插入
- 透過 Flyline 分析預估繞線延遲

## 平面規劃演算法

### 切割法 (Min-cut / Partitioning)

以遞迴方式將晶片區域和邏輯電路反覆分割：先將晶片垂直切割為兩半，將邏輯分配到兩側；再水平切割每個子區域，繼續分配邏輯。這種方法計算效率高，適合早期平面規劃探索。

### 解析法 (Analytical Floorplanning)

將區塊位置表示為連續變數，定義目標函數 (例如總線長 + 面積懲罰項)，使用數值最佳化方法求解。常見的解析法包括二次線長最小化 (quadratic wirelength minimization) 和非線性規劃。

### 模擬退火法 (Simulated Annealing)

以隨機擾動區塊位置的方式逐步最佳化，搭配溫度參數控制收斂速度。模擬退火法品質好但計算較慢，適合中小型設計。這也是 eda4 中 v2f-pnr 所採用的方法。

### 整數線性規劃 (Integer Linear Programming, ILP)

將區塊位置量化為離散網格，建立線性約束和目標函數。ILP 可以保證找到最佳解，但運算時間隨問題規模指數成長，實務上只適用於區塊數量很少的設計。

### 商業工具

- **Synopsys Fusion Compiler**：整合平面規劃、擺置、時鐘樹合成、繞線的全流程工具
- **Cadence Innovus**：與 Fusion Compiler 齊名的業界標準實體設計工具

這些商業工具提供自動化平面規劃、擁塞分析、功耗分析、電源完整性分析等進階功能。它們接受以 DEF (Design Exchange Format) 或 Tcl 指令輸入的平面規劃約束。

### 開源工具

- **OpenROAD**：由美国國科會支援的開源 RTL-to-GDS 流程，包含平面規劃模組 (RePlAce 全域擺置、OpenDP 詳細擺置)
- **OpenLANE**：以 OpenROAD 為基礎的完整 ASIC 設計流程，使用 openlane 配置平面規劃參數
- **GrayWolf**：早期的開源平面規劃與擺置工具，主要用於學術研究

## FPGA 平面規劃的特殊性

### 固定架構

與 ASIC 不同，FPGA 的平面規劃受限於廠商預先定義的架構：

- **邏輯拼貼網格 (Logic Tile Grid)**：可程式化邏輯單元 (LUT + FF) 在晶片上規則排列
- **I/O 拼貼 (I/O Tiles)**：分布在晶片周邊，分為多個 I/O bank
- **BRAM 與 DSP 欄位**：在固定間距插入邏輯陣列中的專用區塊
- **時脈區域 (Clock Regions)**：局部時脈網路的分布區域

### iCE40 架構的平面規劃

Lattice iCE40 系列 FPGA 是 eda4 專案中 v2f-pnr 所針對的目標架構。iCE40 的平面規劃特點：

- 晶片由規則的邏輯拼貼陣列構成，每個拼貼包含一個可程式化邏輯區塊 (PLB)
- I/O 拼貼位在陣列的上下兩側
- BRAM 和 DSP (如有) 在特定欄位位置插入
- 沒有複雜的時脈區域劃分，時脈網路相對簡單

### Pblocks (區域約束)

FPGA 設計者可以使用 Pblock 或類似機制 (例如 Xilinx 的 pblocks、Intel 的 Logic Lock regions) 將特定邏輯約束到特定的 FPGA 區域。這在以下情況特別有用：

- 將高速邏輯限制在靠近 I/O 接腳的區域
- 隔離不同時脈域的邏輯以減少串擾
- 確保關鍵路徑的邏輯集中在同一區域以縮短延遲
- 管理局部功耗密度

### 在 eda4 中的實作

eda4 的 v2f-pnr crate 針對 iCE40 的固定拼貼網格進行簡單的擺置演算法：

- 初始擺置使用隨機分配 (random initial placement)
- 後續最佳化使用模擬退火 (simulated annealing)
- 目前不支援使用者自訂的平面規劃約束
- 所有邏輯會被分配到可用的邏輯拼貼中，沒有區塊層級的平面規劃概念

## 平面規劃品質指標

評估平面規劃好壞的主要指標包括：

- **線長 (Wirelength)**：總繞線長度越短越好，減少延遲和功耗
- **擁塞度 (Congestion)**：繞線資源的使用密度過高可能導致繞線失敗
- **繞線可完成性 (Routability)**：平面規劃是否預留足夠的繞線通道
- **功耗密度 (Power Density)**：局部功耗密度過高會產生熱點
- **溫度分布 (Temperature)**：高溫區域會影響電路速度和可靠度
- **晶片面積 (Die Area)**：面積效率直接影響成本

### ESD 與栓鎖效應防護

平面規劃階段還需要考慮靜電放電 (ESD) 和栓鎖效應 (latch-up) 的防護需求：

- **ESD 防護**：I/O pad 附近必須配置 ESD 防護電路，這些電路通常佔據較大面積，需要在平面規劃中預留空間。I/O 與核心電路之間應保持一定的 ESD 緩衝區。
- **栓鎖效應防護**：在 CMOS 製程中，應在 I/O 電路和 PMOS/NMOS 井區周圍放置足夠多的基體接觸 (substrate contact) 與井接觸 (well contact)，並確保電源網格能夠迅速吸收突波電流。

這些防護結構的佈局需求會影響 I/O 區域和晶片角落的規劃。

## 平面規劃的數位表示

平面規劃的結果通常以以下格式表示：

- **LEF (Library Exchange Format)**：描述巨集區塊的尺寸、接腳位置和障礙區
- **DEF (Design Exchange Format)**：描述晶片尺寸、區塊位置、I/O pad 位置、電源網格定義
- **SDC (Synopsys Design Constraints)**：包含晶片層級的時序和面積約束

在 EDA 流程中，平面規劃階段產出的 DEF 檔案會做為後續擺置和繞線階段的輸入。

## 溫度管理與平面規劃

隨著製程微縮，功耗密度急劇上升，熱管理成為平面規劃中不可忽視的環節。

### 熱點 (Hotspots)

熱點是指晶片上局部溫度顯著高於平均的區域。熱點通常由以下原因造成：

- 高切換活動率的邏輯群聚 (例如時脈閘控密集區域)
- 高功耗的巨集區塊 (如 SRAM、高速 SerDes)
- 散熱路徑受阻的區域 (如被低導熱材料包圍)

### 熱梯度 (Thermal Gradients)

晶片上不同區域的溫度差異會造成熱梯度，影響電晶體的載子遷移率，導致同一晶片上不同路徑的延遲不一致。平面規劃時應避免將高功耗區塊過度集中，並在熱點附近預留散熱通道。

## 平面規劃流程總結

典型的 ASIC 平面規劃步驟如下：

1. **設定晶片尺寸與縱橫比**：根據估計的邏輯面積和目標使用率決定
2. **放置 I/O pad**：根據晶片封裝和 PCB 需求分配 I/O 位置
3. **放置巨集區塊**：將記憶體、類比 IP 等大型區塊放到適當位置
4. **建立電源網格**：規劃電源/接地環和金屬條帶
5. **擺放去耦電容**：在電源網格中插入 decap 單元
6. **擺放標準元件**：先進行全域擺置 (global placement) 評估擁塞狀況
7. **反覆迭代**：根據擁塞和時序分析結果調整平面規劃參數

在 FPGA 設計中，步驟簡化為：

1. **選擇 FPGA 型號**：由邏輯容量和 I/O 數量決定
2. **定義 Pblock 區域** (可選)：約束特定邏輯至特定區域
3. **自動化 P&R**：由廠商工具自動完成擺置與繞線

## 平面規劃與 PDN 的相互影響

平面規劃和 PDN 設計並非獨立流程，而是緊密耦合的：

- **區塊位置影響電源分布**：高功耗區塊若集中在晶片一角，該區域的 IR drop 會明顯增加
- **電源網格阻礙繞線**：密集的電源條帶會減少繞線通道，必須在電源完整性和繞線可完成性之間取得平衡
- **decaps 佔用面積**：去耦電容佔據大量晶片面積，需要在平面規劃中預留空間
- **電源域邊界**：不同電壓域的邊界需要一定的隔離距離，影響區塊之間的間距

因此，現代 EDA 工具將平面規劃和 PDN 合成視為一個反覆迭代的聯合最佳化問題。

## 結論

平面規劃和電源分配網路設計是決定晶片能否成功的關鍵步驟。一個不良的平面規劃會導致繞線擁塞、時序違規、IR drop 過大，甚至使晶片完全無法工作。隨著製程持續微縮到 3nm 以下，電源完整性、熱管理和製程變異的挑戰日益嚴峻，平面規劃的重要性只會有增無減。在 eda4 專案中，v2f-pnr 針對 iCE40 這類相對簡單的 FPGA 架構進行擺置，雖然目前尚未實作完整的平面規劃功能，但對於理解實體設計的基本原理提供了紮實的入門基礎。此外，edp-gr (v2f-pnr 中的繞線器) 在處理 iCE40 的固定拼貼網格時，其整體流程也間接反映了平面規劃的關鍵取捨：在固定的資源佈局下，如何透過最佳化演算法達到最小的線長和可接受的擁塞程度。
