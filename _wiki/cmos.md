# CMOS: Complementary Metal-Oxide-Semiconductor

## 概述

CMOS（Complementary Metal-Oxide-Semiconductor，互補式金屬氧化物半導體）是目前製作積體電路（IC）最主流的技術。它利用互補的 p 型與 n 型 MOSFET（金屬氧化物半導體場效電晶體）組成邏輯閘，以極低的靜態功耗實現數位與類比電路。從微處理器、記憶體到 FPGA，幾乎所有現代晶片都採用 CMOS 製程。

---

## MOSFET 基本結構

MOSFET 是一種電壓控制開關，具有四個端子：

- **閘極（Gate, G）**：控制通道導通與否的多晶矽或金屬電極，與通道之間由二氧化矽（SiO2）絕緣層隔開。
- **源極（Source, S）**：載子的來源端。
- **汲極（Drain, D）**：載子的流出端。
- **基體（Body / Bulk, B）**：矽基板，通常連接至固定電位（nMOS 接 GND，pMOS 接 Vdd）。

當閘極對源極的電壓（Vgs）超過臨界電壓（Vt）時，通道形成，電晶體導通；否則截止。因為閘極氧化層的絕緣特性，MOSFET 的輸入阻抗極高，靜態下閘極幾乎不抽取電流。

---

## nMOS 與 pMOS

CMOS 使用兩種互補的電晶體：

| 特性 | nMOS | pMOS |
|------|------|------|
| 通道載子 | 電子（n-type） | 電洞（p-type） |
| 導通條件 | Vgs > Vt（高電位導通） | Vgs < Vt（低電位導通） |
| 傳遞強訊號 | 強 0、弱 1 | 強 1、弱 0 |
| 基體接法 | GND（0 V） | Vdd（電源） |

nMOS 在傳導邏輯 0 時表現良好（閘極電壓為 Vdd，源極接近 GND），但在傳導邏輯 1 時會因為閘極-源極電壓差縮小而無法將電壓拉升到完整的 Vdd，產生 Vdd - Vt 的衰減。pMOS 則是對稱的情況：傳遞強 1，但傳遞 0 時會留下 |Vtp| 的壓降。

CMOS 將 nMOS 與 pMOS 配對使用，讓訊號擺幅可以達到完整的電源軌（rail-to-rail），這是 CMOS 數位電路最重要的優勢之一。

---

## CMOS 反相器

反相器（Inverter）是最簡單也是最重要的 CMOS 邏輯閘，由一個 nMOS 和一個 pMOS 組成：

```
     Vdd
      |
    pMOS
      |
  IN --+-- OUT
      |
    nMOS
      |
     GND
```

- **輸入為 1（Vdd）**：nMOS 導通，pMOS 截止，輸出被下拉至 GND（0）。
- **輸入為 0（GND）**：pMOS 導通，nMOS 截止，輸出被上拉至 Vdd（1）。

因為在任何穩定狀態下，nMOS 與 pMOS 只有一個導通，從 Vdd 到 GND 之間沒有直流導通路徑，所以靜態電流極小（僅有漏電流）。

### 電壓傳輸特性（VTC）

CMOS 反相器的電壓傳輸曲線（Voltage Transfer Characteristic, VTC）描述了 Vout 對 Vin 的關係：

- **高增益區**：當 Vin 接近 Vdd/2 時，nMOS 與 pMOS 同時部分導通，產生極高的電壓增益，輸出急遽翻轉。
- **邏輯臨界點 Vm**：Vout = Vin 的工作點，設計上通常設在 Vdd/2 附近。
- **雜訊邊限**：因為 VTC 的陡峭轉換，CMOS 具有極佳的雜訊容忍度。NMH（高電平雜訊邊限）= Voh - Vih，NML（低電平雜訊邊限）= Vil - Vol。

## 基本邏輯閘

CMOS 邏輯閘由兩部分網路構成：**上拉網路（Pull-Up Network, PUN）**使用 pMOS 將輸出拉至 Vdd，**下拉網路（Pull-Down Network, PDN）**使用 nMOS 將輸出拉至 GND。PUN 與 PDN 互為對偶。

### NAND 閘（2-input）

需要 4 顆電晶體：2 個串聯 nMOS（下拉） + 2 個並聯 pMOS（上拉）。

- 只在兩個輸入皆為 1 時輸出 0（nMOS 串聯導通，pMOS 並聯截止）。
- 否則輸出為 1。

### NOR 閘（2-input）

需要 4 顆電晶體：2 個並聯 nMOS（下拉） + 2 個串聯 pMOS（上拉）。

- 只在兩個輸入皆為 0 時輸出 1（pMOS 串聯導通，nMOS 並聯截止）。
- 否則輸出為 0。

### AND / OR 閘

AND 由 NAND 加反相器構成，OR 由 NOR 加反相器構成，各需 6 顆電晶體。

### XOR 閘（2-input）

典型的 XOR 需要 8-12 顆電晶體，常見設計包括傳輸閘（transmission gate）XOR（約 6 顆傳輸閘 + 反相器）或串聯互補架構。

## CMOS 的優勢

CMOS 之所以成為積體電路的主流技術，主要原因包括：

1. **極低的靜態功耗**：在穩定狀態下，CMOS 閘中 Vdd 到 GND 沒有直流通路，靜態電流僅有 pn 接面的逆向漏電流與次臨界漏電流（subthreshold leakage）。這使得 CMOS 可以在單一晶片上整合數十億個電晶體而不至於過熱。

2. **高雜訊邊限**：rail-to-rail 輸出擺幅與陡峭的 VTC 轉換區提供了優異的雜訊容忍度，讓數位設計更加穩健。

3. **可縮放性**：隨著製程微縮，電晶體尺寸、電壓與功耗可以等比降低，使 CMOS 持續了數十年的進步。

4. **邏輯擺幅完整**：不像 nMOS-only 或 pMOS-only 邏輯會損失電壓位準，CMOS 的互補結構保證輸出達到完整的 Vdd 或 GND。

5. **設計簡單且規則化**：只需調整電晶體的通道寬度（W）即可控制驅動能力，電路設計規則相對直觀。

## 功率消耗

CMOS 的功率消耗由兩部分組成：

### 動態功耗

動態功耗（Dynamic Power）是電路在切換狀態時消耗的功率，主要來自對負載電容的充放電：

```
P_dynamic = alpha * C_L * Vdd^2 * f
```

其中：

- **alpha**：活動因子（activity factor），平均每個時脈週期切換的機率。
- **C_L**：負載電容（包含閘極電容、接面電容與連線電容）。
- **Vdd**：電源電壓。
- **f**：時脈頻率。

從公式可以看出，降低 Vdd 對功耗有平方級的改善效果，這也是製程微縮持續降壓的主要動力之一。此外，電容來自負載電容與短路電流（short-circuit current，在輸入轉換期間 nMOS 與 pMOS 同時短暫導通）。

### 靜態功耗

靜態功耗（Static Power）來自電晶體截止時的漏電流：

```
P_static = I_leakage * Vdd
```

主要漏電流來源包括：

- **次臨界漏電流（subthreshold leakage）**：Vgs < Vt 時仍存在的微弱電流，隨 Vt 降低呈指數增長。
- **閘極氧化層穿隧電流（gate oxide tunneling）**：氧化層極薄時，量子穿隧效應導致的閘極漏電。
- **接面漏電流（junction leakage）**：源極/汲極與基體之間的逆向偏壓漏電。

在先進製程（28nm 以下），靜態功耗在總功耗中的佔比顯著上升，成為設計中的重要考量。

## 摩爾定律與 CMOS 微縮

### 摩爾定律

戈登·摩爾（Gordon Moore）在 1965 年預測，晶片上電晶體數量約每兩年翻倍。這個預測在數十年間持續成立，驅動了半導體產業的快速發展。

### 丹納德微縮（Dennard Scaling）

羅伯特·丹納德在 1974 年提出了經典的等比微縮理論：當電晶體尺寸縮小為原來的 1/k 倍時：

- 閘極長度：L -> L/k
- 閘極氧化層厚度：tox -> tox/k
- 電源電壓：Vdd -> Vdd/k
- 臨界電壓：Vt -> Vt/k
- 電晶體密度：增加 k^2 倍
- 延遲：降低為 1/k
- 功耗密度：保持不變

這意味著更小、更快、更省電、更便宜的晶片可以同時實現。

### 丹納德微縮的終結

大約在 2005 年（對應 90nm - 65nm 節點），丹納德微縮開始失效，主要原因：

1. **漏電流急遽增加**：Vt 的降低導致次臨界漏電流指數增長。
2. **電壓無法等比降低**：Vt 無法等比例降低（否則漏電流過大），導致 Vdd 也無法繼續降低。
3. **功率密度達到極限**：雖然單一電晶體功耗降低，但密度增長更快，導致單位面積的功率密度不降反升。這被稱為「功率牆」（power wall）。

從此，處理器時脈頻率的快速提升停止（約在 3-4 GHz 左右停滯），產業轉向多核心架構與架構最佳化來維持性能成長。

## CMOS 製程節點演進

CMOS 製程節點的命名（製程節點或技術節點）傳統上代表閘極（通道）長度。以下是主要節點的發展歷程：

| 節點 | 量產年份 | 特點 |
|------|----------|------|
| 180nm | 1999 | 經典 CMOS，Vdd ~1.8V |
| 130nm | 2001 | 銅導線取代鋁導線 |
| 90nm | 2004 | 應變矽技術提升載子遷移率 |
| 65nm | 2006 | 超淺接面、低 k 介電層 |
| 45nm | 2008 | 高 k / 金屬閘極（HKMG）導入，解決閘極漏電問題 |
| 32nm / 28nm | 2010 | 28nm 成為長壽節點，HKMG 成熟化 |
| 22nm / 14nm / 16nm | 2014 | FinFET 量產（Intel 22nm，台積電 16nm，三星 14nm） |
| 10nm | 2018 | FinFET 最佳化，極紫外光（EUV）開始導入 |
| 7nm | 2019 | EUV 量產（台積電/三星） |
| 5nm | 2020 | 更密集的 FinFET，EUV 層數增加 |
| 3nm | 2022-2023 | 台積電 3nm 量產，GAA（Gate-All-Around）開始過渡 |

現代的製程節點名稱已經不再嚴格對應實際的閘極長度，更多的是市場行銷命名。例如 7nm 節點的實際物理尺寸可能接近 10nm 以上。

## FinFET：平面 CMOS 的繼任者

當製程微縮到 28nm 以下，傳統平面 MOSFET 面臨嚴重的短通道效應（Short-Channel Effects, SCE），包括：

- 漏感應能降（DIBL）
- Vt 滾降（Vt roll-off）
- 次臨界擺幅劣化

### FinFET 結構

FinFET（鰭式場效電晶體）透過將通道改為垂直的鰭狀結構來解決這些問題：

- 閘極從三面（頂部 + 兩側）包圍通道，因此也稱為**三閘極電晶體（tri-gate transistor）**。
- 更好的閘極控制能力，有效抑制短通道效應。
- 次臨界擺幅更接近理想值（60 mV/decade）。
- 可以在更低電壓下運作。

Intel 在 2011 年的 22nm 節點率先量產 FinFET，隨後台積電 16nm 與三星 14nm 也導入 FinFET。從 14nm/16nm 到 5nm，FinFET 一直是主流結構。

### FinFET 的挑戰

- 鰭片的高度與寬度需要精確控制，製程複雜度大幅提升。
- 鰭片數量（number of fins）決定了驅動能力，無法像平面 CMOS 那樣連續調整。
- 自熱效應（self-heating）因為結構的隔熱特性而加劇。

### 超越 FinFET

在 3nm 以下，業界開始轉向 GAA（Gate-All-Around）結構，其中奈米片（nanosheet）或奈米線（nanowire）完全被閘極包圍，提供最佳的通道控制。三星在 3nm 導入 GAA（MBCFET），台積電則在 2nm 才轉向 GAA。

## SOI：絕緣層上矽

SOI（Silicon on Insulator，絕緣層上矽）是一種替代性的基板技術，在矽晶圓中嵌入一層氧化層（通常是埋氧層，Buried Oxide, BOX）來隔離電晶體與基板：

### SOI 的優點

- **減少接面電容**：BOX 隔離減少了源極/汲極與基板之間的接面電容，動態功耗更低。
- **改善隔離**：電晶體之間透過氧化層而非反向偏壓的 pn 接面隔離，減少了閂鎖效應（latch-up）的風險。
- **抗輻射能力強**：適合航太與國防應用。

### SOI 的類型

- **PD-SOI（Partially Depleted SOI）**：頂層矽較厚，部分空乏。
- **FD-SOI（Fully Depleted SOI）**：頂層矽極薄（約 5-20nm），通道完全空乏，次臨界擺幅更好，變異性更小。STMicroelectronics 的 28nm FD-SOI 是代表性製程。

### SOI 與 Bulk CMOS 的比較

SOI 在相同節點下通常能提供更好的性能與功耗，但晶圓成本更高。Bulk CMOS（傳統的矽基板 CMOS）則因成本較低且製程成熟而佔據了絕大多數的市場。FD-SOI 在物聯網（IoT）與車用電子領域有不錯的定位。

## CMOS 在 FPGA 中的角色

FPGA（Field-Programmable Gate Array）本質上就是一顆大型的 CMOS 晶片。所有 FPGA 的內部結構——包括可編程查找表（LUT）、交換矩陣（switch matrix）、連線資源（routing fabric）、記憶體區塊（BRAM）、數位訊號處理單元（DSP）——都是用 CMOS 電晶體實現的。

### FPGA 與 CMOS 的相關性

- **可編程互連**：FPGA 中的 pass transistor（通常使用 nMOS 或 transmission gate）用於建立可編程的連線路徑。了解 nMOS 只能傳強 0、弱 1 的特性，對於理解 FPGA 為何需要在某些路徑加入電平恢復電路（level restorer）至關重要。

- **查找表（LUT）**：LUT 實際上是以 SRAM 儲存的真理表，由 CMOS SRAM 單元（通常為 6T 結構）構成。

- **高效能區塊**：DSP 與 BRAM 採用全客製 CMOS 設計，以達到最佳的延遲與功耗。

### iCE40 所使用的 CMOS 製程

Lattice iCE40 FPGA 系列採用約 40nm 或 55nm 的低功耗 CMOS 製程。這是一個較成熟的節點，因此在靜態功耗與成本之間取得了良好的平衡，適合低密度、低功耗的應用場景。

## 與 eda4 的關聯

eda4 專案的 verilog2fpga 工具鏈的終極目標是產生可以在 FPGA 上執行的位元流（bitstream）。而這些 FPGA——例如 iCE40——的底層物理實現正是 CMOS 技術。具體來說：

- **v2f-synth** 將 Verilog 合成為 netlist，這個 netlist 最終會被映射到 FPGA 的 CMOS 查找表與其他資源上。
- **v2f-pnr** 進行布局與繞線，實際上是在安排 CMOS 電晶體所構成的可編程連線。
- **v2f-bitstream** 產生的 CRAM（Configuration RAM）位元流，其內容就是載入到 CMOS SRAM 單元中的配置資料。
- **v2f-programmer** 透過 JTAG 或 SPI 將位元流寫入 FPGA 晶片，啟動其中的 CMOS 電路。

理解 CMOS 的基礎知識——從電晶體開關行為到動態功耗公式——對於進行數位設計與 FPGA 開發都是非常重要的背景知識。

## 關鍵指標

### 臨界電壓（Vt）

MOSFET 開始導通所需的閘極-源極電壓。Vt 的選擇影響延遲與漏電的權衡：較低的 Vt 帶來更快的電晶體切換速度，但會增加次臨界漏電流。

### 電源電壓（Vdd）

晶片的運作電壓。從早期的 5V（180nm 以前），到 3.3V、1.8V、1.2V，再到先進製程的 0.7V 左右。

### Ion / Ioff 比

導通電流（Ion）與截止電流（Ioff）的比值，反映了電晶體的開關品質。典型的 Ion/Ioff 比在 10^5 到 10^7 之間。

### 閘極延遲

訊號從輸入變化到輸出的延遲時間，由電晶體的驅動能力與負載電容決定。在 CMOS 中，延遲大致與 (C * Vdd) / Ion 成正比。

### 漏電流

電晶體截止時流過的微小電流。在先進製程中，漏電流造成的靜態功耗已經成為重要問題，也是低功耗設計的主要挑戰之一。

## CMOS 對數位設計的意義

理解 CMOS 的基本原理對於數位邏輯設計非常重要，原因如下：

1. **為什麼數位訊號是 0 和 1**：CMOS 的 rail-to-rail 輸出特性使得二值邏輯表示成為自然選擇——0 代表 GND，1 代表 Vdd。

2. **為什麼電平會衰退**：當使用單一 nMOS 傳遞訊號（如 pass transistor logic 或某些 FPGA 繞線結構）時，高電平會被衰減到 Vdd - Vt。這解釋了為什麼某些電路需要電平恢復電路（level restorer）或 transmission gate（同時使用 nMOS 與 pMOS 並聯）。

3. **為什麼靜態功耗低**：因為穩定狀態下沒有直流通路，CMOS 可以將數十億電晶體整合在同一晶片上。

4. **為什麼需要時脈**：雖然 CMOS 靜態功耗低，但動態功耗來自切換。時脈訊號是所有訊號中活動因子最高的（alpha = 1），因此時脈網路是晶片中功耗最高的部分之一。

5. **為什麼不能忽視漏電**：在深次微米製程中，漏電流顯著增加，即使電路未在運作也會消耗功率。這在電池供電的 IoT 裝置中尤為關鍵。

CMOS 技術從 1980 年代開始主導半導體產業，至今仍是所有數位晶片的物理基礎。從最簡單的反相器到最先進的 CPU 與 FPGA，底層的電晶體行為始終遵循相同的物理原理。掌握 CMOS 的基礎知識，是深入理解數位積體電路設計的必要前提。
