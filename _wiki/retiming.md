# Retiming（Leiserson-Saxe 演算法）

## 什麼是 Retiming

Retiming（重新計時）是一種同步電路的最佳化技術，透過在組合邏輯閘之間移動暫存器（flip-flop）來改善電路的效能、面積或功耗，同時**不改變電路的功能行為**。

核心思想很直觀：如果一個電路中的組合邏輯延遲分配不均，某些路徑的延遲遠大於其他路徑，那麼時脈週期就必須遷就最長的路徑，導致整體效能受限。透過重新分配暫存器的位置，可以將長路徑上的邏輯拆分到多個時脈週期，實現更短的時脈週期和更高的吞吐量。

關鍵在於：暫存器的移動必須保持電路的**外部行為不變**——也就是說，從輸入到輸出的延遲（以時脈週期數計算）可以改變，但電路的邏輯功能必須完全相同。

## 歷史背景

Retiming 由 Charles Leiserson 和 James Saxe 在 1983 年首次提出，是他們的經典論文 *"Retiming Synchronous Circuitry"*（收錄於 *Algorithmica*, 1991 年）的核心貢獻。這篇論文證明了：

1. Retiming 問題可以形式化為一個線性規劃問題
2. 存在一個多項式時間演算法（基於 Bellman-Ford）來求解最優 retiming
3. 最小化時脈週期和最小化暫存器數量是兩個可分開處理的目標

Leiserson-Saxe 演算法至今仍是同步電路最佳化中最經典的理論成果之一，被廣泛應用於 FPGA 和 ASIC 的合成工具中。

## Retiming 模型

一個同步電路被建模為一個**有向圖** G(V, E, d, w)：

- **節點 V**：組合邏輯閘（AND、OR、MUX 等）
- **邊 E**：連線
- **d(v)**：節點 v 的組合邏輯延遲
- **w(e)**：邊 e 上的暫存器數量（0 表示純組合連線，>0 表示有暫存器）

這個圖模型捕捉了電路的關鍵特徵：組合邏輯的延遲和暫存器的位置。

## Retiming 移動操作

Retiming 有兩種基本移動操作：

### 正向 Retiming（Forward Retiming）

將一個暫存器從節點的所有輸入邊移動到該節點的所有輸出邊：

- 每個輸入邊的暫存器計數減 1
- 每個輸出邊的暫存器計數加 1

正向 retiming 相當於將暫存器「推過」組合邏輯閘，從輸入側移動到輸出側。

### 反向 Retiming（Backward Retiming / Borrowing）

將一個暫存器從節點的所有輸出邊移動到該節點的所有輸入邊：

- 每個輸出邊的暫存器計數減 1
- 每個輸入邊的暫存器計數加 1

反向 retiming 是正向 retiming 的逆操作，將暫存器從輸出側「拉回」到輸入側。

這兩種操作組合起來，可以實現任意暫存器的重新分配。每次移動操作都是**局部且可逆的**，因此整個 retiming 過程可以逐步進行，而不會破壞電路的正確性。

## Retiming 不等式

Retiming 的核心數學工具是**滯後變數（lag）** r(v)，表示通過節點 v 向後（從輸出到輸入）移動的暫存器數量。

對於一條邊 e：u → v（從 u 到 v），retiming 後的暫存器數量為：

```
w_r(e) = w(e) + r(v) - r(u)
```

其中：
- w(e) 是原始的暫存器數量
- r(u) 是源節點 u 的滯後值
- r(v) 是目標節點 v 的滯後值

**可行性約束**：retiming 後的暫存器數量必須非負：

```
w_r(e) = w(e) + r(v) - r(u) ≥ 0
```

這條不等式是分析 retiming 問題的基礎。所有與 retiming 相關的約束條件都可以透過這組不等式來表達。

## 兩個最佳化目標

Leiserson-Saxe 演算法解決兩個主要的最佳化問題：

### 目標 1：最小化時脈週期

找到一個 retiming 方案，使得電路在最小的時脈週期下能夠正常運作。

給定目標時脈週期 T，如果存在某個 retiming 使得所有暫存器到暫存器路徑的延遲 ≤ T，則稱 T 是**可行的**。

時脈週期可行性的條件是：對於任意節點對 (u, v) 且 u 到 v 的延遲 ≥ T，在 u 和 v 之間必須至少有一個暫存器。這可以轉化為對暫存器數量的約束條件。

### 目標 2：最小化暫存器數量

在滿足給定時脈週期 T（或最小可行時脈週期）的前提下，找到一個 retiming 方案使得電路使用的暫存器總數最少。

這是一個線性規劃問題，目標函數是總暫存器數量，約束條件是 retiming 不等式的可行性條件和時脈週期約束。

## Leiserson-Saxe 演算法步驟

完整的 Leiserson-Saxe 演算法包含以下步驟：

### 步驟 1：計算全源最短路徑矩陣

在所有節點之間計算以暫存器倒數為權重的最短路徑。這個矩陣用於後續的可行性檢查。

具體做法是將邊的權重設為 w(e)，然後使用 Floyd-Warshall 或 Johnson 演算法計算所有節點對之間的最短路徑。

### 步驟 2：對目標時脈 T 計算可行性約束

對於給定的目標時脈週期 T，找出所有路徑延遲 > T 的節點對 (u, v)。對這些節點對施加約束：在 retiming 後，u 和 v 之間的路徑上至少需要一個暫止器。

### 步驟 3：求解差值約束系統

將所有可行性約束轉化為一組差值不等式（difference constraints），每條不等式形如：

```
r(v) - r(u) ≤ c
```

這組不等式可以使用 **Bellman-Ford** 演算法（或最長路徑演算法）來求解。如果存在解，則 Bellman-Ford 會找到一組滿足所有約束的 r(v) 值。

### 步驟 4：計算 Retiming 方案

根據求解得到的 r(v) 值，應用 retiming 不等式 `w_r(e) = w(e) + r(v) - r(u)` 計算 retiming 後每條邊上的暫存器數量。如果某個 w_r(e) 小於 0，則表示不存在可行 retiming。

### 步驟 5：對時脈週期進行二分搜尋

由於時脈週期 T 是整數（或離散值），可以在可能的時脈週期範圍內進行**二分搜尋**：對每個候選 T 執行步驟 2-4，找到最小的可行 T。

最小可行 T 必然在 [0, W] 範圍內，其中 W 是原始電路中的最大路徑延遲。

## Retiming 的應用

### 用於時脈週期最佳化

這是最常見的 retiming 應用。透過將暫存器從短延遲路徑移動到長延遲路徑上，可以將長路徑拆分為多個時脈週期，從而降低整體的時脈週期。

例如：一個包含延遲 3ns 和延遲 7ns 的兩級管線，時脈週期必須至少為 7ns。透過 retiming，可以在 7ns 的邏輯中間插入一個暫存器，將它拆分為 3ns + 4ns，時脈週期即可降至 4ns。

### 用於面積最佳化

Retiming 也可以減少暫存器的數量：

- **合併冗餘暫存器**：當多條路徑上的暫存器可以在同一位置合併時，retiming 可以將它們合而為一
- **消除無效暫存器**：某些暫存器可能只是因為設計層面的原因而存在，retiming 可以揭示它們是多餘的

需要注意的是，最小化暫存器數量和最小化時脈週期可能是互相衝突的目標。例如，為了達到更短的時脈週期可能需要增加暫存器。

### 用於功耗最佳化

Retiming 對功耗的影響主要體現在：

- **時脈閘控（Clock Gating）**：透過 retiming 將暫存器集中在可以更容易進行時脈閘控的位置
- **降低翻轉活動率（Switching Activity）**：合適的 retiming 可以減少不必要的暫存器翻轉
- **降低時脈負載**：合併暫存器可以減少時脈樹的負載，從而降低時脈功耗

## 經典範例：兩級管線平衡

最經典的 retiming 範例是兩級管線的平衡問題：

**原始電路**：
- 第一級：組合邏輯 A（延遲 2ns），後接暫存器
- 第二級：組合邏輯 B（延遲 7ns），後接暫存器
- 時脈週期必須 ≥ 7ns（受最長路徑限制）

**目標**：將時脈週期降至 5ns

**Retiming 方案**：
1. 將邏輯 B 拆分為 B1（延遲 4ns）和 B2（延遲 3ns）
2. 將第一級暫存器向前移動到 B1 和 B2 之間
3. 新的管線結構：A + B1（總延遲 6ns）→ 暫存器 → B2（延遲 3ns）
4. 時脈週期降至 max(6, 3) = 6ns

若需要進一步降低（如 5ns），可以反向移動暫存器到 A 之前，重複上述過程，直到兩級的延遲盡可能接近。

這個範例說明了 retiming 的本質：它不能消除邏輯延遲（總延遲不變），但可以透過重新分配暫存器來**重新分布延遲到不同的時脈週期**。

## Retiming 在 FPGA 中的應用

FPGA 的架構為 retiming 提供了理想的應用場景：

- **豐富的暫存器資源**：每個 LUT 都有一個配套的 flip-flop，幾乎是「免費」提供的
- **LUT-FF 配對**：LUT 和 flip-flop 在 FPGA 的邏輯單元中已經配對好，retiming 只需要決定是否使用這個 flip-flop，而不需要額外的面積開銷
- **合成時的暫存器搬移**：Xilinx 和 Intel（Altera）的 FPGA 合成工具通常在綜合（synthesis）階段就進行 retiming，利用 LUT-FF 配對的靈活性來最佳化效能

由於 FPGA 中暫存器的「邊際成本」幾乎為零，retiming 在 FPGA 合成中的應用非常積極——幾乎總是傾向於使用更多的暫存器來換取更短的時脈週期。

## Retiming 在 Yosys/ABC 中的實作

Yosys 和 ABC 是目前開源領域最重要的合成工具鏈，它們提供了 retiming 的實作：

### ABC 中的 retime 指令

ABC 提供 `retime` 和 `dretime` 兩個指令：

- **retime**：基於 Leiserson-Saxe 演算法，針對最小化時脈週期進行最佳化
- **dretime**：延遲導向的 retiming，更積極地插入暫存器以降低時脈週期

### 使用方法

在 Yosys 中，可以透過以下指令選用 ABC 的 retiming：

```
yosys> synth -top top_module
yosys> abc -dff  # 啟用 DFF 最佳化（包含 retiming）
```

或者在 ABC 腳本中直接使用：

```
abc> retime -o  # 輸出 retiming 後的電路
```

## 在 eda4 中的關係

在 eda4 專案中，`v2f-synth`（合成工具）**不執行 retiming**——它的作用是將 Verilog RTL 直接映射到目標 FPGA 的邏輯單元（LUT + FF）。`v2f-synth` 的輸出是純粹的組合與暫存器實例化，不涉及暫存器的重新分配。

然而，當使用者選擇 `--backend yosys` 來使用外部合成工具時，Yosys 內部會呼叫 ABC 進行邏輯最佳化，其中就包含了 retiming 步驟。這使得使用 yosys 後端的設計可以獲得額外的時脈週期最佳化，這是純 Rust 合成後端目前不具備的能力。

未來，如果 `v2f-synth` 要加入進階的時序最佳化，retiming 將是一個重要的擴展方向。

## 管線 Retiming 詳解

管線 retiming 是 Leiserson-Saxe 演算法最直接的應用：

### 問題描述

給定一個 k 級管線，每級的組合邏輯延遲分別為 d1, d2, ..., dk，時脈週期等於 max(di)。如果某些級別的延遲遠大於其他級別，則整體效能受限。

### 解決方案

透過 retiming 將暫存器在管線各級之間移動：

1. 將長延遲級別中的一部分邏輯拆分到相鄰的短延遲級別中
2. 重複直到各級延遲盡可能均衡

### 數學性質

對於總延遲 D = Σdi，在理想情況下，可達到的理論最小時脈週期為 D/k（總延遲除以管線級數）。但實際上受到以下限制：

- 不可分割的邏輯單元（如一個加法器）不能被拆分到多級
- 回饋路徑上的暫存器數量不能隨意改變

## 局限性

Retiming 雖然強大，但也有其固有的限制：

### 迴路上的暫存器總數不變

這是最重要的限制之一：對於電路中的任何**有向迴路**（cycle），retiming 不能改變該迴路上暫存器的總數量。這是因為 retiming 移動只在迴路的邊上重新分配暫存器，而不會增加或減少迴路中的暫存器總數。

這一性質可以從 retiming 不等式中推導出來：對於一個迴路 v1 → v2 → ... → vk → v1，retiming 後的總暫存器數量為：

```
Σw_r(e) = Σw(e) + r(v1) - r(v1) + r(v2) - r(v2) + ... = Σw(e)
```

所有滯後項互相抵消，因此總數不變。

### 不適用於非合成電路

Retiming 僅適用於結構固定、邏輯閘層級的電路。對於以下類型的電路，retiming 無法直接應用：

- 非同步電路（asynchronous circuits）
- 包含三態匯流排或双向訊號的電路
- 包含類比或混合訊號的電路
- 行為級（behavioral-level）的描述

### 不能改變 I/O 延遲

Retiming 可以改變內部暫存器的位置，但不能改變電路**介面**的暫存器行為。通常的做法是將 I/O 邊視為不可移動的暫存器，或使用虛擬節點來建模 I/O 約束。

### 時序不變性僅限於功能

Retiming 保證電路的功能正確，但不會保留電路的**時序細節**（如輸入輸出延遲的時脈週期數）。對於需要精確時脈週期數的設計（如某些通訊協定），retiming 後的電路可能需要重新驗證時序。
