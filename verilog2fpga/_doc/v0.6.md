# v0.6 — `fpga!` 巨集解析器

## 目標

實作 `v2f-rust-macros` 的 `fpga!` proc-macro 完整解析，讓使用者能在 Rust 中直接以 Verilog-like 語法撰寫硬體描述，自動產生 `HdlModule`。

## 變更內容

### `v2f-rust-macros/src/lib.rs`

- 新增遞迴下降解析器，支援以下語法：
  - `module <name> { ... }` — 模組宣告
  - `input/output/inout <name>: <width>,` — 埠宣告
  - `reg [<msb>:<lsb>] <name>,` 或 `reg <name>,` — 暫存器宣告
  - `always(posedge|negedge <signal>) { <stmt>; ... }` — 同步區塊
  - `<target> <= <expr>;` — 非阻塞賦值 (→ `HdlStmt::Nonblocking`)
  - `<target> = <expr>;` — 阻塞賦值 (→ `HdlStmt::Blocking`)
  - `assign <target> = <expr>;` — 連續賦值
  - 運算式：常數、識別符號、索引 (`[i]`)、範圍 (`[msb:lsb]`)、二元運算 (`+ - & | ^`)
- 新增 `Expr` / `HdlStmt` AST 型別
- 新增 `Cursor` 字串解析器（空白/逗號跳過、關鍵字邊界檢查）
- 新增 `generate_code()` 產生 Rust builder 呼叫（`v2f_rust::HdlModule` chain）
- 新增 `gen_expr()` 遞迴產生 `v2f_rust::HdlExpr` token
- 使用 `proc_macro2::TokenStream` + `quote!` 生成程式碼
- 自動處理 proc-macro tokenization 產生的多餘空白（`[ 25 : 0 ]` vs `[25:0]`）
- 2 個單元測試：tokenized 格式與 human-friendly 格式皆可正確解析

### `v2f-rust/src/hdl.rs`

- 新增 `HdlModule::inout(name, width)` — 雙向埠
- 新增 `HdlModule::blocking(target, value)` — 阻塞賦值 (→ `HdlStmt::Blocking`)

### `v2f-rust/src/lib.rs`

- 新增 `pub use v2f_rust_macros::fpga;` — 從 v2f-rust 直接匯出 `fpga!` 巨集

### `v2f-rust/Cargo.toml`

- 新增依賴：`v2f-rust-macros = { path = "../v2f-rust-macros" }`

### `v2f-cli/src/main.rs`

- `--lang rust` 路徑改為使用 `v2f_rust::fpga!` 巨集取代硬編碼 builder chain

## 使用範例

```rust
use v2f_rust::fpga;

let module = fpga! {
    module Blinky {
        input clk: 1,
        output led: 4,

        reg [25:0] counter,

        always(posedge clk) {
            counter <= counter + 1;
        }

        assign led = counter[25:22];
    }
};
```

產生等價於：
```rust
HdlModule::new("Blinky")
    .input("clk", 1)
    .output("led", 4)
    .reg("counter", 26)
    .dff("counter", HdlExpr::Add(
        Box::new(HdlExpr::Ident("counter".into())),
        Box::new(HdlExpr::Const(1, 26)),
    ))
    .assign("led", HdlExpr::Range(
        Box::new(HdlExpr::Ident("counter".into())),
        25, 22,
    ))
```
