# v0.7 — FPGA 電路視覺化工具 (v2f-viz)

## 目標

建立一個 **純 Rust 原生桌面 GUI 應用**（eframe/egui），可互動視覺化呈現：

1. **電路圖** — 從 JSON netlist 解析 cells 與連接，以圖形化方式展示
2. **佈局圖** — 從 ASC 檔案解析 tile 分配，以 FPGA 網格方式展示
3. **繞線圖** — 疊加 netlist 連線至 tile 佈局上，展示訊號路由

## 視圖設計

### 1. 電路 (Circuit) 視圖

- 從 JSON netlist 解析 cells (`$_INPUT_`, `$_ONE_`, `$_ADD_`, `$_DFF_P_`, `$_AND_`, `$_OUTPUT_`)
- 依照 cell type 分層佈局（左到右：INPUT → ONE/ADD → DFF → AND → OUTPUT）
- 每層內平均分配垂直位置
- 同一 net ID 的 cells 之間繪製連線
- 每個 cell 顯示名稱 (eg `$0`, `$27`) 與類型 (eg `$_DFF_P_`)
- cell 依類型上色
- 可拖曳平移、滾輪縮放

### 2. 佈局 (Layout) 視圖

- 從 ASC 解析 `.logic_tile` 項目
- 根據 device 決定 tile grid 大小 (eg HX8K = 32×20)
- 使用中的 tile 以綠色高亮，未使用以暗色顯示
- 滑鼠懸停顯示 cell 名稱與座標
- IO tile (port_clk, port_led) 以黃色標記
- 左下角顯示 device 名稱與使用率

### 3. 繞線 (Routing) 視圖

- 疊加 tile grid 與 netlist 連線
- 將 cell → tile 映射後，在同一個 net 的 cells 之間繪製連線
- 不同 net 使用不同顏色
- 展示訊號如何透過 tile 網路傳遞

## 互動功能

| 功能 | 實作方式 |
|------|---------|
| 拖曳平移 | Primary mouse button drag，累積 `pan` offset |
| 滾輪縮放 | `smooth_scroll_delta.y` → 乘以 zoom factor (範圍 0.05× ~ 10×) |
| 懸停查看 | `response.interact_pointer_pos()` 判斷 tile 是否在 rect 內 |
| 重置視圖 | 按鈕將 `pan` 歸零、`zoom` 設為 1.0 |
| 檔案載入 | CLI 參數 (`v2f-viz out.json out.asc`) + 拖放檔案 |
| 視圖切換 | 頂部選單列三按鈕：電路 / 佈局 / 繞線 |

## 測試

```sh
cargo build -p v2f-viz

# 開啟 blinky netlist
cargo run -p v2f-viz -- ../_out/blinky_vlog.json

# 開啟 blinky netlist + layout
cargo run -p v2f-viz -- ../_out/blinky_vlog.json ../_out/blinky_vlog.asc
```
