# v0.8 — 交叉驗證：純 Rust vs Yosys/nextpnr/icepack

## 目標

建立自動化交叉驗證框架，系統性比對純 Rust EDA 管線與標準開源工具鏈（Yosys + nextpnr + icepack）的每一階段輸出，確保功能等效性。

## 現況

```
純 Rust:   blinky.v → v2f-synth → v2f-pnr → v2f-bitstream → blinky.bin
外部工具:  blinky.v → yosys    → nextpnr → icepack         → blinky_ref.bin
兩者從未被比對過。
```

無 CI、無 golden 測試、`v2f-synth` 無測試目錄、`v2f-pnr` 測試僅檢查字串存在、`v2f-bitstream` 測試不與 icepack 比較。

## 分層驗證策略

三層比對，由淺入深：

```
JSON 層 (synth)  — v2f-synth vs yosys      → 拓撲/port/cell 對等
ASC 層 (pnr)     — v2f-pnr   vs nextpnr     → 佈局約束滿足、繞線完全
BIN 層 (pack)    — v2f-bitstream vs icepack  → binary identical
```

### 第一層：JSON 網表比對（v2f-synth vs Yosys）

**不要求 binary identical**，但需檢查：

| 檢查項 | 方法 |
|--------|------|
| port 數量與名稱 | 兩者 ports 的 name/direction/bits 一致 |
| cell 數量與類型 | 兩者 cells 的 type 集合一致（忽略 $name 差異） |
| net 拓撲 | 每個 netname 的 bits 長度一致；cell 間連接關係相同 |
| 支援的 Verilog 子集 | 每個範例電路兩種後端皆可綜合，不報錯 |

實作：`v2f-synth/tests/cross_valid.rs`

```rust
#[test]
fn test_json_vs_yosys_blinky() {
    let v_src = include_str!("../../examples/blinky/blinky.v");
    let pure = v2f_synth::synthesize(v_src, "blinky");
    let yosys = run_yosys_synth(v_src, "blinky"); // subprocess
    assert_json_ports_equiv(&pure, &yosys);
    assert_json_cell_types_equiv(&pure, &yosys);
    assert_json_nets_equiv(&pure, &yosys);
}
```

### 第二層：ASC 佈局比對（v2f-pnr vs nextpnr）

不要求 cell 位置相同（隨機種子不同），但需檢查：

| 檢查項 | 方法 |
|--------|------|
| 所有 cell 皆被放置 | ASC 中 tile count == JSON cell count + port count |
| 無重疊放置 | 無兩個 cell 佔用同一 tile |
| 所有 net 皆有路徑 | 每個 net 在 ASC 中存在對應 wiring |
| IO cell 位於合法位置 | port cell 在 IO row 或 logic edge |
| 繞線完全 | 無 open net（source/sink 之間有連續 wire segment） |

實作：`v2f-pnr/tests/cross_valid.rs`

```rust
#[test]
fn test_asc_vs_nextpnr_blinky() {
    let json = get_synth_json("blinky.v");
    let pure_asc = v2f_pnr::run_pnr(&json, Device::HX8K);
    let nextpnr_asc = run_nextpnr(&json, Device::HX8K);
    assert_all_cells_placed(&pure_asc, &json);
    assert_all_cells_placed(&nextpnr_asc, &json);
    assert_no_overlap(&pure_asc);
    assert_no_overlap(&nextpnr_asc);
    // 統計比較：tile 使用數、平均繞線長度（不要求相等，但應合理）
    assert_placer_stats_reasonable(&pure_asc, &json);
}
```

### 第三層：位元流 binary 比對（v2f-bitstream vs icepack）

給定相同 ASC 輸入，純 Rust 與 icepack 輸出**必須 binary identical**。

| 檢查項 | 方法 |
|--------|------|
| 相同 ASC → 相同 BIN | 兩者 bitstream 的 SHA256 一致 |
| CRC 正確 | 兩者 CRC-32 皆符合 iCE40 規範 |
| 確定性 | 相同 ASC 重複打包 3 次結果一致 |

實作：`v2f-bitstream/tests/cross_valid.rs`

```rust
#[test]
fn test_bin_vs_icepack_minimal() {
    let asc = include_str!("../_fixtures/minimal_hx1k.asc");
    let pure_bin = pack_pure(asc, Device::HX1K);
    let icepack_bin = run_icepack(asc);
    assert_eq!(pure_bin, icepack_bin, "bitstream mismatch");
}

#[test]
fn test_pack_deterministic() {
    let asc = include_str!("../_fixtures/minimal_hx1k.asc");
    let a = pack_pure(asc, Device::HX1K);
    let b = pack_pure(asc, Device::HX1K);
    assert_eq!(a, b);
}
```

## 測試電路清單

| 電路 | 檔案 | 複雜度 | JSON 比對 | ASC 比對 | BIN 比對 |
|------|------|--------|-----------|----------|----------|
| blinky | `examples/blinky/blinky.v` | 1 input, 1 output, 26-bit counter | ✅ | ✅ | - |
| adder | `examples/adder/adder.v` | 4-bit adder | ✅ | ✅ | - |
| 單一組合邏輯 | `assign out = a & b \| c` | 3 input, 1 output, 1 cell | ✅ | - | - |
| DFF 暫存器 | `always @(posedge clk) q <= d` | 1-bit reg | ✅ | - | - |
| 8-bit 計數器 | 類似 blinky 但縮小 | 8-bit counter | ✅ | ✅ | - |

BIN 層比對需要 nextpnr+icepack 產出相同 ASC 作為輸入，因此僅適用 fixtures 或固定 nextpnr 輸出。

## E2E 驗證腳本

`test_cross.sh`：

```bash
#!/bin/bash
set -e
echo "=== 交叉驗證：純 Rust vs Yosys/nextpnr/icepack ==="

echo ""
echo "--- JSON 層 (v2f-synth vs yosys) ---"
cargo test -p v2f-synth cross_valid 2>&1

echo ""
echo "--- ASC 層 (v2f-pnr vs nextpnr) ---"
cargo test -p v2f-pnr cross_valid 2>&1

echo ""
echo "--- BIN 層 (v2f-bitstream vs icepack) ---"
cargo test -p v2f-bitstream cross_valid 2>&1

echo ""
echo "=== 完成 ==="
```

僅在外部工具安裝時執行（`v2f check` 確認 yosys + nextpnr + icepack 皆可用），否則跳過。

## 驗收標準

1. `cargo test` 全部通過（無外部工具時跳過 cross-valid tests）
2. blinky 的 JSON 層：port 數/名/方向一致，cell 類型集合一致
3. adder 的 JSON 層：同上
4. blinky 的 ASC 層：所有 cell 被放置，無重疊
5. `minimal_hx1k.asc` 的 BIN 層：純 Rust 與 icepack 輸出 binary identical
6. `test_cross.sh` 一鍵執行所有交叉驗證

## 測試隔離

使用 `#[cfg_attr(not(has_external_tools), ignore)]` 或環境變數 `V2F_SKIP_EXTERNAL=1` 控制：預設不執行需外部工具的測試，僅在 CI 或明確啟用時執行。

```rust
// 在測試中
fn has_external_tools() -> bool {
    std::process::Command::new("yosys").arg("--version").output().is_ok()
        && std::process::Command::new("nextpnr-ice40").arg("--version").output().is_ok()
        && std::process::Command::new("icepack").arg("--version").output().is_ok()
}

#[test]
fn test_json_vs_yosys_blinky() {
    if !has_external_tools() { return; }
    // ...
}
```
